# 誰是知識王

分隊搶答的即時連線問答遊戲。分數就是籌碼，隊長下注買答題權，隊伍答案由隊員多數決產生。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 連線版（首頁）。建房後把 `?room=房號` 的連結傳給朋友即可加入 |
| `solo.html` | 單機試玩版，隊友與對手由電腦模擬，用來驗證玩法或沒人可玩時練習 |
| `connection-test.html` | Firebase 連線診斷，出問題時的第一個檢查點 |

## 規則摘要

- 每隊起始 10,000 分，分數可以是負的
- 每回合公布領域但不公布難度，隊長暗押 500 / 1000 / 1500 / 2000 / 2500 / 3000
- 翻牌後輪流叫價（每次至少 +500，上限 3000），出價低的一方永遠有機會再加
- 沒人再加時，注最高的隊獨得答題權；跟平則進搶答對決
- 答對得難度分（簡單 1,000／中等 1,500／困難 2,000／地獄 3,000），答錯賠掉自己押的注
- 隊伍答案採多數決，隊長票算 1.5 票
- 題庫 286 題，七個領域（常識、數學、歷史、地理、動漫、電玩、KPOP）四種難度

## 技術

單一 HTML 檔，無建置流程。連線使用 Firebase Realtime Database（asia-southeast1）與匿名登入，房主的瀏覽器擔任裁判推進階段。
